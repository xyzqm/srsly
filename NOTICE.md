# Third-party data redistributed by srsly

srsly's own source code is MIT (see [LICENSE](LICENSE)). This file covers the datasets the
repository **redistributes** — the generated files that are committed here and served to every
visitor. Their licences are not MIT, and the share-alike ones travel with the files.

There is a second attribution file, [`scripts/data/ATTRIBUTION.md`](scripts/data/ATTRIBUTION.md),
and the split between them is deliberate:

- **That file** covers build-time **inputs** — corpora and word lists the build scripts read to
  grade vocabulary, which are never shipped to a browser.
- **This file** covers build **outputs** that are shipped. Redistribution is what triggers the
  attribution and share-alike obligations, so the shipped files are the ones that need a notice
  a recipient can actually find.

Every file below is generated by a script in `scripts/`, never edited by hand. Each script
names its source URL at the top, so any entry here can be traced to the download it came from.

## Dictionaries served to the client

### `public/cedict.json` — 7.6 MB

Built by [`scripts/build-cedict.mjs`](scripts/build-cedict.mjs) from **CC-CEDICT**, the
community Chinese–English dictionary published by MDBG.

Source: <https://www.mdbg.net/chinese/dictionary?page=cc-cedict>
Licence: **Creative Commons Attribution-ShareAlike 4.0 International** (CC BY-SA 4.0)

The emitted JSON is a derivative work: entries are reshaped to `{ p, m }`, pinyin is converted
from numbered to tone-marked form with the syllable-dividing apostrophe applied, and name-only
senses are filtered out (`scripts/lib/nameFilter.mjs`). It is therefore redistributed under the
same CC BY-SA 4.0 licence.

### `public/jmdict.json` — 3.1 MB

Built by [`scripts/build-jmdict.mjs`](scripts/build-jmdict.mjs) from **JMdict**, the Japanese–
Multilingual Dictionary of the Electronic Dictionary Research and Development Group (EDRDG),
obtained through the [jmdict-simplified](https://github.com/scriptin/jmdict-simplified)
release packaging.

Source: <https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project>
Licence: <https://www.edrdg.org/edrdg/licence.html> — **Creative Commons
Attribution-ShareAlike 4.0 International** (CC BY-SA 4.0)

JMdict is the property of the Electronic Dictionary Research and Development Group, and is used
in conformance with the Group's licence. srsly claims no copyright over that material.

The EDRDG asks that software displaying dictionary content acknowledge it on screen; srsly does
so in the footer of the app itself, not only here.

### `public/esdict.json` — 5.5 MB · `public/frdict.json` — 4.7 MB

Built by [`scripts/build-esdict.mjs`](scripts/build-esdict.mjs) and
[`scripts/build-frdict.mjs`](scripts/build-frdict.mjs) from **Wiktionary** extracts published by
[kaikki.org](https://kaikki.org/) (Tatu Ylonen's `wiktextract`).

Source: <https://kaikki.org/dictionary/Spanish/> and <https://kaikki.org/dictionary/French/>
Licence: **CC BY-SA 4.0** (Wiktionary's own licence; kaikki.org redistributes under it)

Both files carry definitions taken from Wiktionary and are derivative works, redistributed
under CC BY-SA 4.0. The same extracts also supply the inflected-form → lemma tables in
`lib/data/es-forms.*` and `lib/data/fr-forms.*`, and the grammar tables in
`lib/data/es-grammar.json` and `lib/data/fr-grammar.json`, which are covered identically.

### `lib/data/han-decomp.json` — 350 KB

Built by [`scripts/build-radicals.mjs`](scripts/build-radicals.mjs) from **Make Me a Hanzi** by
Shaunak Kishore, itself derived from the Unihan Database and CJKlib.

Source: <https://github.com/skishore/makemeahanzi>
Licence: **GNU Lesser General Public License v3** (LGPL-3.0)

**This one is different from every other entry here**, and
[`scripts/data/ATTRIBUTION.md`](scripts/data/ATTRIBUTION.md) sets out the reasoning at length:
it is the only shipped file whose source is copyleft rather than share-alike, so the LGPL
travels with the emitted JSON rather than stopping at the build. In practice that obliges srsly
to keep this notice, state the licence where the data is used, and let a recipient obtain and
substitute their own version of the LGPL'd portion — which the emitted file supports, being a
mechanical and regenerable subset. It does **not** place srsly's own code under the LGPL.

The more obvious source, CHISE's `ids.txt`, is GPLv2 — a materially heavier obligation on a
file that ships — which is why it was not used.

## Level and frequency data

### `lib/data/cefr-levels.*` (Spanish) and `lib/data/fr-levels.*` (French)

CEFR band assignments derived at build time from open corpora and cross-checked against the
CEFR-J Wordlist and the Octanove Vocabulary Profile. The inputs and their licences —
including **Lexique 3** (CC BY-SA 4.0) and Octanove (CC BY-SA 4.0) — are documented in
[`scripts/data/ATTRIBUTION.md`](scripts/data/ATTRIBUTION.md).

**These are not official CEFR word lists.** The CEFR defines no such list; these tables are a
frequency approximation and should not be presented as an authoritative mapping.

### `lib/data/jlpt-*` (Japanese)

JLPT level assignments from <https://github.com/elzup/jlpt-word-list>, combined with JMdict
readings and glosses. The JLPT itself publishes no official vocabulary list; these are the
community lists in common use.

### `lib/data/hsk-vocab.*` (Chinese)

HSK 2.0 level assignments (5,000 words). Checked-in data with no generator in this repository;
glosses are supplemented from CC-CEDICT, so the CC BY-SA 4.0 notice above applies to those.

## Runtime dependency worth naming

**kuromoji** (<https://github.com/takuyaa/kuromoji.js>), Apache License 2.0, ships its own IPADIC
morphological dictionary. It is a normal npm dependency rather than data vendored here, and is
used server-side only.

## If you are reusing this

Take the code under MIT. If you take the generated data files, they stay under **CC BY-SA 4.0**
(or LGPL-3.0 for `han-decomp.json`), which means keeping attribution and licensing your changes
alike. Regenerating them yourself from the scripts does not change that — the obligation follows
the source data, not the download.
